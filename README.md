# shaka-277-trial

Disposable public fixture for live acceptance checks on
[shakacode/shaka#277](https://github.com/shakacode/shaka/issues/277). Synthetic content only;
safe to delete.

`bin/greet NAME` prints a greeting. Use `bin/greet --plain [NAME]` to omit the
exclamation point; the name defaults to `world`. Run `bin/setup`, `bin/test`, and `bin/validate`.
